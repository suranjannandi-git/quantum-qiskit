# quantum-qiskit

## Setup

Create and activate a virtual environment:

```bash
python3.12 -m venv venv
source venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Create a `.env` file from the example and add your values:

```bash
cp .env.example .env
```

## Running Notebooks

You can open and run the notebooks directly from your IDE.

Alternatively, launch Jupyter Notebook in your browser:

```bash
jupyter notebook <path/to/notebook.ipynb>
```
